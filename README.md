# Visionary Studio Website

Premium black-and-gold portfolio and booking landing page for Visionary Studio, Bangalore.

## Included
- Responsive mobile/desktop design
- Gallery powered by existing repository wedding and pre-wedding assets
- Embedded studio MP4 films with user-controlled playback
- WhatsApp enquiry form (opens WhatsApp with a pre-filled message; does not store submissions)
- Click-to-call, Instagram and WhatsApp links

## Deploy
Static site — no build command required. Set the project root to the repository and publish the root directory on GitHub Pages, Netlify, or Vercel.
